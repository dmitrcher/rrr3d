# Контакты кузова и края трассы: исследование v60

Цель полного соответствия Windows остаётся незавершённой. Windows/PhysX — неизменённый эталон; настройки автомобилей сохранены.

Новый вариант исправляет выбор опорного полигона и исключает внутренние рёбра между копланарными треугольниками. Windows SDK независимо подтверждает флаги рёбер и исходные координаты. Ограничение вращения перенесено до решения контактов: удар может превысить предел, как в Native. Порядок пар контактов исследуется отдельно.

В итоговом варианте сохранены все 65 точных сценариев из 608; 543 имеют воспроизводимые расхождения. Все 291 независимый тест совпадают с Native в двух прогонах. 53 проверки сборки прошли. Проваленные промежуточные варианты сохранены отдельно.

Первый удар о бордюр: ошибка положения уменьшилась с 0.513261 до 0.000004 исходных единиц. Это не критерий успешности всего исправления: за 600 шагов максимум положения 4.243929 → 4.192130, максимум ошибки поворота 21.212256° → 36.066142°. Поэтому вариант выключен по умолчанию и не заменяет обычную игру. Удар в полёте после исправления внутренних рёбер сохраняет результаты v59.

Следующий проверяемый механизм — обратное преобразование положения треугольника через кватернион. На одних и тех же Native-входах оно уже точно воспроизводит шесть ранее отличавшихся координат. Далее необходимо проверить геометрию контактов, полный ответ решателя и всю историю движения, затем сохранить все независимые тесты.

Исходники, установщик с проверкой хешей и компактные отчёты: `tools/calibration/experimental/box-triangle-v60`. Полные данные публикуются отдельным исследовательским архивом. Проверки одной машины без ИИ не заменяют ещё отсутствующее полное сравнение Windows GameCar с Mac GameCar.
