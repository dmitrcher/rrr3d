# Контактный этап v35: сохранённые точки и ошибки

Экспериментальная Mac/Jolt реализация теперь совпадает с нативным эталоном
Windows/PhysX 2.8.4 во всех 12 сценариях контакта кузова с плоской землёй,
на всех 120 шагах каждого сценария. Два повтора совпадают внутри платформы.
Вся лестница 00–03 пройдена: 189 сценариев, 22680 отсчётов одного прогона.
Это измеренная область совпадения; вся физика игры ещё не согласована.

## Причина и исправление

В v34 совпадали первый контакт и первые 480 состояний решателя, но последующие
шаги расходились. Расширенная трассировка оригинального PhysXCore показала:

- при сохранении контакта Native оставляет локальные точки обоих акторов;
- совпадение проверяется по локальным расстояниям и направлениям нормалей;
  порог расстояния равен 0.2 от суммы skin widths, порог cosine — 0.999;
- нормальная ошибка берётся из нового геометрического разделения, а боковые
  компоненты пересчитываются из перемещения сохранённых точек;
- этот пересчёт использует матричную формулу quaternion, затем material path
  использует другую форму с `w*w - 0.5`; округлённый quaternion различает их;
- локальное плечо силы сохраняется. Его повторное вычисление как разницы
  мировых координат даёт дополнительное округление на Mac.

`NativeContactCache.h` сохраняет собственные точки Mac, проверяет расстояния
и нормали, пересчитывает боковую ошибку и плечо силы с явным float32 порядком
операций. Адаптер передаёт их через ContactManifold/Settings к существующему
Native normal-row эксперименту. Координаты, ошибки и состояния Windows в
обычный Mac-прогон не подставляются. ИИ и GameCar gameplay не вызываются.

Флаг `RRR3D_EXPERIMENT_NATIVE_CONTACT_CACHE=1` выключен по умолчанию. Требуется
полная цепочка SDK/адаптера v32–v34 и mask31. Текущая согласованная область —
нормальные ограничения dynamic/static при нулевом трении и restitution.
Канонический игровой адаптер и установленные игры не заменены этим кандидатом.

| Полные контакты с землёй | 12 × 120 шагов, два повтора, точно |
| Выключен только новый cache flag | Все физические состояния прежнего v34 сохранены |
| Первые прежние отличающиеся шаги, четыре варианта высоты/скорости, масса 300 | Все 160 внутренних строк v/ω/λ/K/bias/error/плечо совпадают |

| Трассировка Native с увеличенным лимитом | 4 сценария × 2 повтора; все 120 состояний исходного эталона сохранены |

| Восстановление патча | Все шесть файлов по SHA совпадают с проверенной сборкой |
| Полная Mac Debug сборка | arm64, подпись, 1200 ресурсов, 14 видео |
| CTest | 53/53, 18.07 секунды |

SHA эталона неизменны: SpringProbe.exe
`8c331b7ea35ed6181c0f8dd52cddca451f60c817d381d360cb53852e8c49ed9d`,
PhysXCore.dll `c03f0e20e99a6ca8d72c8627cf3b0108036a734123f75c652c2b78d3043dbdbb`.
Отладчик читает оригинальный Core; вмешательство проверено относительно полного
исходного прогона. Произвольные указатели, padding и неинициализированные поля
не используются как доказательство численного совпадения.

Числа основного журнала имеют девять значащих цифр. Для внутренних Native
float32 полей сравнивается значение после восстановления float32, без допусков.
Измеренные входы используются только в отдельном helper для проверки формулы;
основная проверка выполняется настоящим Mac-пробником на его собственных данных.

## Что остаётся

72 более широких наклонных контакта проверены по 120 шагов дважды с cache flag
и без него. Новый вариант точно совпал в двух сценариях (pitch 0 и 0.0001,
плоская земля); 70 сценариев ещё расходятся. Максимальная ошибка координат
0.002236822134789187, скорости 0.04754252218259157 единиц мира/с. Относительно
выключенного cache flag максимальная ошибка координат выросла в 21 сценарии,
скорости — в 27. Поэтому широкое применение кандидата не принято.

64 отдельные геометрические проверки v34 сохраняют 70/306 несовпадающих точек
и две прежние регрессии; v35 не меняет генератор геометрии. Полная матрица 608
сценариев пока имеет только историческую оценку v27 (572 расхождения на профиль).
Подвеска, сцепление, боковое скольжение, тормоза, вращение, restitution,
динамические пары и игровые трассы остаются частью активной общей цели.

Следующий шаг — локализовать ошибки наклонных contact frames и плеч/инерции,
прежде чем объявлять контакты в целом пройденными и переходить к подвеске.
Полное совпадение игры этим релизом не утверждается.

## Повторение

После сборки патчей v34 и `native-contact-cache-v35.patch`:

```sh
python3 tools/calibration/experimental/run_isolation.py \
  --platform mac --probe rrr3d_physics_spring_probe \
  --reference-dir windows-isolation --contact-v35-cache --out mac-isolation-v35
```

Runner сохраняет `isolation-run.json`, хеши, два повтора и результат каждого
этапа. `implemented_stages_passed` означает только этапы 00–03. Полный архив
содержит измерения, исходники, снимки до/после, пробники и переносимые проверки.
Порядок автономной проверки описан в
[`native-cache-v35/README.md`](../tools/calibration/experimental/native-cache-v35/README.md).
