# v50: preserve the requested center of mass

Status: experimental progress; the goal of complete Windows/Mac equivalence is still active.

The DirtDevil free-spin fixture exposed an extra float32 rounding in the Mac shape wrapper. The requested local center x is `0.10000000149011612` (word `3dcccccd`). Subtracting the child shape center to construct an offset, then adding that child center in `GetCenterOfMass`, returned `0.10000000894069672` (word `3dccccce`). Actual original PhysX body captures retain the requested value. This error affects the body center and the reported actor origin.

The default-off flag `RRR3D_EXPERIMENT_NATIVE_EXACT_SHAPE_COM=1` stores the requested center explicitly in `OffsetCenterOfMassShape`. The relative offset remains the existing target-minus-child offset for geometry operations. The adapter sets this mode before body creation. Mass, inertia, engine power, tire coefficients and test inputs are unchanged.

The optional shape serialization writes a reserved all-NaN marker (three words `7fc24d43`), followed by the relative offset and exact center. Ordinary shapes preserve the original binary bytes; patched readers accept valid legacy records. Exact-mode records require a patched reader. A separately compiled actual pre-change writer confirms the ordinary output is still byte-identical. Round-trip checks cover centers, offsets, bounds, user data, a shared child and the next stream record.

Two fresh repetitions of controls and candidates cover 291 fixtures. All 17 stock mixed-spin histories now match Windows in every declared float32 state field, including position, velocity, quaternion and angular momentum. The 24-case investigation has 23 exact cases; `body-slide-x` remains. The retained 72 tilted-contact cases, six older contact cases and 189 isolated cases all match: 290/291 overall. Controls with the new flag off reproduce the v49 candidate histories. Decimal midpoint printing differences are compared as exact float32 words, without tolerance.

The full Debug application was rebuilt, packaged and signed (1200 assets, 14 movies), and all 53 CTests passed. These are build and numerical checks; an interactive race has not been certified for this version. The historical broad 608-case suite has not yet been rerun with this candidate. These counts do not establish complete game parity.

Read-only contact diagnostics add `RRR3D_CONTACT_ITERATION_ROWS=1` together with `RRR3D_CONTACT_ROWS=1`. `RRR3D_CONTACT_NATIVE_TRACE_STEP` filters iteration records. Events expose normal and both friction calculations and application phases. Two repetitions preserve the actual full Mac history. Two original Windows debugger captures likewise preserve the immutable original history and reproduce the defined numerical rows.

The next lead is at the first ground contact, tick 10. Inverse mass, world inverse inertia and all eight normal effective masses match. The first Mac row already differs after applying normal/friction impulses. A diagnostic model using the recorded equal deltas shows that multiplying a precomputed inverse-inertia response differs from constructing torque from force before multiplying by inverse inertia. Combining the normal and friction forces before the linear update reproduces the first Windows linear velocity, but one angular component still differs. This is a lead, not a complete reconstructed friction kernel. Additional force assembly, point-velocity and impulse accumulation differences need separate verification. No friction fix is accepted in v50.

Source is in `tools/calibration/experimental/native-exact-com-v50`, with byte-exact before/after snapshots and an adjacent patch. Apply it on the v49 experimental adapter and SDK chain identified in `base.json`. All experiments remain default off. The evidence package contains original measurements, a Mac probe and the verifier; it is not a game installer. `verify.py --package PATH --out REPORT` audits bundled evidence, and `replay.py --package PATH --out NEW_DIRECTORY` executes fresh two-repeat controls and candidates with the bundled probe.
