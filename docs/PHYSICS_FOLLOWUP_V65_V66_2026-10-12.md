# Продолжение после v64: отклонённые предположения и чтение сжатых журналов

Полный checkpoint v64 остаётся основным измеренным вариантом: 65/608 точных сценариев, 543 открытых. Параметры Windows и автомобилей не изменяются. Дополнительные изменения v65/v66 выключены по умолчанию и не считаются устранением оставшихся ошибок.

v65 проверяет выбор системы координат контакта по порядку создания акторов. В двух повторах 17 выбранных сценариев меняется только border-grounded, причём немного: максимум положения 3.89581954 → 3.89566526. Большая ошибка остаётся. 291 независимый тест и 53 CTest прошли; полного прогона 608 сценариев для этой гипотезы нет. Один ошибочный запуск старого пробника после неудачной компиляции явно отклонён; принятые записи требуют новый флаг в бинарнике и выполнены после успешной сборки.

v66 проверяет перенос подготовки пружин/шин на жёсткие ограничители подвески. xCar/приземление улучшилось с 0.00000821064 до 0.000000135932, но podushka/engine2 ухудшилось с 0.00106010 до 0.00219045; найденные жёсткие массы не совпадают с Native. Входные позы к этой точке уже немного различаются, поэтому различие масс само по себе не доказывает дефект формулы. Все 291 независимая проверка и 53 CTest прошли. Полная матрица не запускается для варианта, который уже ухудшил выбранные сценарии.

Следующий необходимый разбор — подготовка ограничителя на одинаковых сохранённых Native-входах: точка приложения, локальные координаты, якобиан, обратная инерция, масса, velocity bias, затем построчное решение и связанные контакты. Входные значения должны быть сверены до выводов о формуле; подгонка коэффициентов запрещена. Остаётся большая ошибка на третьем физическом шаге удара о границу.

Инструмент `tools/calibration/compare.py` теперь читает `.jsonl.gz` напрямую, в том числе когда указанный исходный `.jsonl` был сжат. SHA256 считается по распакованным исходным байтам, поэтому идентичность эталона сохраняется. Подтверждены оба режима чтения, все 24 сценария исходного файла и исходный хеш. Это убирает необходимость возвращать большие старые журналы на диск для независимых проверок.

У checkpoint v64 сверены все 436 членов ZIP и реально скачанные с GitHub файлы — потоково, без сохранения ещё одной большой копии. Дополнительные 121 закрытый журнал сжаты с проверкой исходного SHA по архиву и обратного преобразования gzip; освобождено около 2 GiB. Последние полные истории v64 и Native-эталоны сохранены. Caffeinate продолжает работать.
