# MotorRock: первоначальный аудит истории силы шин v20 — 2026-10-11

Цель устранения всех расхождений активна. Это эксперимент, без замены установленных сборок v14. Общая проверка v20 ещё не завершена.

Новые Windows-пробы показывают: tire callback получает силу прошлого решённого шага, включая мягкую пружину и жёсткий упор. На первом контакте она нулевая. Mac ранее использовал текущую величину во время каждого прохода решателя. Новый строгий флаг `RRR3D_EXPERIMENT_TIRE_FORCE_HISTORY=1` сохраняет необрезанную силу N после шага и преобразует её в импульс по текущему dt для следующего шага. При reset/логической потере контакта история сбрасывается; однокадровое повторное касание требует отдельной проверки.

Оригинальный callback ограничивает силу проекцией гравитационной нагрузки, включая нулевую проекцию. Прежний Mac helper в случае нулевой нагрузки сохранял необрезанную силу; эта ошибка тоже исправлена под новым флагом. Это может относиться и к контакту с вертикальной поверхностью; сам такой переход ещё не доказан новой моделью.

Источник проверен на 620 новых случаях при N=4: 576 случаев скольжения по 24 шага, 36 случаев упора по 6 и 8 случаев нулевой нагрузки по 12. Всего 14 136 измерений. В семье скольжения максимальная ошибка скорости без frozen pose снизилась с 2,01655 до 0,16286, углового момента — с 595,121 до 23,778. Первый шаг совпадает в пределах 0,0000051 скорости. При frozen pose остаётся максимум скорости 0,00334. В упоре максимум скорости 0,0000163; при нулевой нагрузке 0,0000158 против прежних 0,02086.

Скалярная модель по измеренным SDK лучам и предыдущим состояния́м проверяет 888 sample в 68 случаях. Максимум ошибки силы 0,006277 N. Использование текущей силы отвергнуто на 1 371 канале, исключение упора из прошлой силы — на 60, отсутствие ограничения нулевой нагрузки — на 95. Это проверки force channels, а не числа отдельных сценариев. Модель ограничена совпадающими по позиции колёсами, frozen orientation и статической плоской опорой.

Диагностика под новым флагом показывает фактические cached/capped значения tire callback и source slip caches. Физическая формула бокового slip уже включала нормальную составляющую скорости; прежний лог показывал другой, плоский угол внутреннего контроллера Jolt. Физическую формулу этого угла менять не потребовалось. Без флага сохраняется прежний формат значений; новые физические поля/семантику нельзя смешивать с прежними raw spring force без учёта фазы.

Четыре полных режима прошли по 608 случаев / 255 864 измерения. Все имеют 572 случая выше строгих допусков. При source mesh, default, RMS положения 0,176270 (v19: 0,187578), скорости 0,065631 (0,069072), углового момента 88,025 (88,105). При source mesh/frozen положение 0,127387, скорость 0,042824. Native mesh по-прежнему значительно расходится; регрессия border-grounded остаётся. 50 CTest нового C++ прототипа прошли; модель добавлена отдельным CTest.

Патч меняет один cpp адаптера поверх опубликованного SDK/adapter chain v14–v19. SDK layout v20 не меняется; частный runtime хранит новую историю. SHA256 базы и результата сохранены. Прежние spring bias/final/lost/cold/stop/friction-zero флаги обязательны для полного исследуемого прототипа; mesh/frozen выбираются отдельно.

Дальше: N1/2/8, переменный dt и повторное касание, относительное ускорение динамической опоры, порядок/warm start шин, два полных disabled control и игровые прогоны. Эти проверки обязательны до повышения статуса эксперимента; средние ошибки и зелёные тесты не закрывают общую цель.
