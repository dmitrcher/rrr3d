# MotorRock: аудит v21 — 2026-10-11

Цель устранения всех расхождений активна. Установленные Windows/Mac сборки v14 не заменены. Ни один новый эксперимент не включён по умолчанию: полная матрица по-прежнему имеет 572 из 608 случаев выше строгих допусков. Эталон — исходная Windows/PhysX 2.8.4 сборка; SHA256 полного эталонного JSONL `4bcc66c8f4f28ccb77a07759175573cc56d72035636642617fae4e75addecc1f`.

## Подтверждённая поправка подвески

PhysX использует исходные коэффициенты spring/damper независимо от угла кузова относительно нормали контакта. Jolt делил их на косинус этого угла. Патч `experimental/suspension-raw-v21.patch` поверх SDK v20 сохраняет исходные коэффициенты только при строгом `RRR3D_EXPERIMENT_SUSPENSION_RAW=1` и активном source spring final. Направление силы остаётся нормалью поверхности. ABI и заголовки SDK не меняются. SHA256 базы/результата сохранены в соседнем manifest.

240 наклонённых проб при N1/N4 проверяют массы 300/1200, одно/четыре активных колеса, pitch −0,3/−0,1/0/0,1/0,3, покой/продольную/боковую скорость, две пружины, включённую/отключённую тягу. Повторный Windows захват опубликованного исходника точно воспроизвёл все физические величины и SDK wheel axes. Независимая модель 240 первых шагов по измеренным SDK лучам, контактам и инерции даёт максимум ошибки скорости 2,353e−7, положения 5,074e−7, момента 4,520e−5; вариант с делением на cos отвергается в 192 случаях. Это скалярная проверка по геометрии SDK, а не доказательство совпадения всей геометрии между движками.

На 960 измерениях N4 без тяги новый Mac максимум ошибки скорости 0,000270962 против 0,045490624 раньше; положения 0,0000105, углового момента 0,212982. С тягой остаются расхождения скорости до 0,006851737. Поправка подтверждена, но не устраняет все связанные ошибки шин/геометрии.

## Отвергнутый эксперимент шин

Фиксированный боковой импульс из pre-solve скорости и предыдущей силы подвески улучшал небольшую семью проб, но ухудшил RMS положения полной source-mesh/default матрицы с 0,176270 до 7,827197. Полностью удалён из рабочего SDK/адаптера. Сохранён только как `lateral-prescribed-rejected-v21.patch`, с явным статусом rejected. Также не приняты cold/reverse wheel order, ранняя tire phase и направление силы вдоль луча кузова.

Новая скалярная модель lateral envelope проверяет 110 592 канала positive/negative frozen wheel probes на N1/2/4/8 с максимумом ошибки импульса 5,072e−7. Она подтверждает величину, сообщаемую Nx wheel contact API; она **не доказывает**, что весь этот импульс должен безусловно применяться к кузову. Результат rejected полного прогона имеет приоритет.

История силы шин v20 дополнительно проверена при N1/2/8. Модель теперь имеет 272 случая / 3552 измерения, максимум ошибки силы 0,009940 N. Неверная текущая сила отвергается на 5528 каналах, исключение упора — на 240, отсутствие zero-load cap — на 386. Переходы контакта, переменный dt и динамическая опора требуют дальнейшего исследования.

Его область — оригинальная геометрия и GameCar, без игрового lifecycle и renderer; Windows аналог этого CLI ещё не реализован.

Дальше: solver clipping бокового импульса, связь шин с вращением кузова, контактные переходы и переменный dt, истинные карты в Windows runner, затем отдельные детерминированные проверки ИИ/визуального соответствия. Оставшиеся расхождения и карта 64 запрещают объявлять общую цель выполненной.
