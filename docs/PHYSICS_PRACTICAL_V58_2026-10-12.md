# Проверка физики по полным траекториям, v58

Текущая цель — довести Mac до оригинальной Windows/PhysX физики. Уточнённые
критерии и ограничения записаны в `PHYSICS_PORT_PLAN.md`. Цель не достигнута.

Ранее сдвиг первого несовпадения использовался как основная мера прогресса.
Теперь он служит диагностикой. Результат оценивается за всю траекторию:
положение, скорость, ориентация, угловой момент, контакты колёс, ход и сила
подвески. Все коэффициенты автомобиля остаются исходными.

## Подтверждённые исправления

В исходном Windows решателе тяга является ограничением с целевой скоростью
колеса и границами импульса. Прежний Mac путь принудительно прикладывал весь
допустимый импульс даже после достижения целевой скорости. Дефект особенно
заметен на машинах с сильным сцеплением: Monstertruck/wheel2 на первом шаге
разгона получал скорость 2.665766 вместо 2.292982 у Windows.

Второе исправление сохраняет локальную точку и локальную ось строки
подвески при потере земли на один шаг. Windows сохраняет их относительно
кузова; Mac повторно обращал старую мировую точку через новое положение
машины. На высокой скорости это существенно меняло плечо силы и поворот.
Прямые повторные записи оригинального решателя подтвердили сохранение
локальных координат при изменившемся положении кузова.

| Сценарий, все 600 шагов | Ошибка положения v57 → v58 | Ошибка ориентации v57 → v58 |
|---|---:|---:|
| Monstertruck/wheel2, разгон | 0.734993 → 0.0944863 | 13.9231° → 0.140600° |
| Monstertruck/wheel1, разгон | 0.734989 → 0.0948520 | 13.9218° → 0.139271° |
| Monstertruck/wheel3, разгон | 0.734935 → 0.0944277 | 13.9248° → 0.140420° |
| Podushka/engine2, разгон | 0.454724 → 0.243679 | 3.57610° → 0.0645209° |
| Контакт с границей | 4.24393 → 4.24393 | 21.2123° → 21.2123° |

Положение и скорость выражены в исходных игровых единицах; метры не
заявляются. Шаг стенда — 1/60 секунды, выборка после решения, индексы с нуля.
Это максимальные ошибки за весь тест, включая съезд с площадки ±500.

## Проверки и ограничения

- Полная матрица: 608 сценариев, 255864 выборки, два одинаковых физических
  прогона Mac. 65 сценариев полностью совпадают по строгому F32 контракту;
  543 сохраняют несовпадения. Это не процент готовности игры.
- 291 независимая проверка физики: контроль и кандидат, по два повтора;
  все сохраняют точное совпадение с Windows.
- 53 проверки проекта прошли после полной пересборки SDK, приложения и
  потребителей. Mac приложение подписано, содержит 1200 ресурсов и 14 видео.
- 10 новых полных прогонов исходного Windows пробника совпадают с ранее
  сохранённым эталоном. Исходный Windows exe и PhysX не изменялись.
- Математика подготовленных осей и плеч проверена на 54 строках, включая
  потерю контакта: 324 слова F32 совпадают при O0 и отдельно при O2.
- GameCar на двух исходных трассах 0/64 проверен с одной машиной и заданным
  вводом: по три повтора с seeds 42/42/999 для контроля и кандидата, по 900
  выборок. Противников, ИИ, игровых обновлений и рендера в этом режиме нет.
  Это проверка повторяемости Mac; Windows/GameCar сравнение ещё требуется.

Нельзя объявлять отсутствие регрессий по сохранению первого несовпадающего
кадра. В `curb-side` максимум ошибки положения вырос с 0.0848257 до 0.0983446;
в `mobility/devildriverBoss/engine1/diagonal-slide` — с 0.00119929 до 0.00226858.
Оба увеличения сохранены в отчёте. Причина первого увеличения связана с
экспериментом локальной строки, второго — с комбинацией anchor/velocity-limit.
Эти связи установлены раздельными прогонами; окончательное исправление
причин ещё не подтверждено.

Следующий приоритет: воспроизвести сохранённые строки **шин**, которые Windows
решает на первом шаге потери контакта, затем повторить проверки съезда и
бордюра. Текущий Mac путь сохраняет пружину, но отключает эти строки шин.
Параллельно остаются граница, совместные контакты и полный игровой ввод.

## Воспроизведение

`tools/calibration/experimental/practical-parity-v58/base.json` описывает
девять файлов поверх точной исследовательской базы v56. Установщик проверяет
все хеши до изменения любого файла; обычный корневой адаптер репозитория
не является этой базой. Полная пересборка обязательна: добавлен кеш локальной
точки/оси в Wheel. Совместимость старых Jolt snapshots не подтверждена.

Все новые флаги выключены по умолчанию. Для совместного кандидата сохранить
исследовательскую цепочку v56 и включить флаги из `base.json`. Старый fitted
профиль не используется; множители тяги, массы и торможения не подгонялись.
Обычная игровая сборка не сертифицирована с этим экспериментом.

Сохраняются исходники до/после, установщик, переносимый проверяющий код
математики, численные отчёты и манифесты. Полные измерения предоставляются
отдельным архивом исследования; материалы не являются релизом готовой физики.
