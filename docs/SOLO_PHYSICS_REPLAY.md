# Воспроизводимая проверка без ИИ

Основной Windows/PhysX–Mac/Jolt стенд уже запускает 608 изолированных физических сценариев без компьютерных игроков. Газ, тормоз, угол колёс, ускорения и импульсы задаются по номеру шага. В парных проверках столкновений второй автомобиль также управляется сценарием. Обычная гонка с ИИ проверяет интеграцию отдельно: одинаковый seed не гарантирует одинаковые решения ИИ после расхождения положений автомобилей.

Добавлен `--solo-physics-replay` в нативный Mac игровой executable. Он загружает выбранную настоящую карту, создаёт ровно одну человеческую машину и использует исходный `GameCar::OnFixedStepDrive`. Режим работает без окна и рендеринга, не вызывает ИИ и игровую прогрессию: нет бонусов, оружия, игровых повреждений и автоматического возвращения на трассу. Физические столкновения с геометрией и декорациями сохранены. `RRR3D_AI_DRIVER=1` не переключает этот режим на ИИ. Пользовательский профиль не изменяется.

900 шагов по 1/60 секунды: оседание, газ, движение накатом, тормоз, задний ход, два поворота, тормоз, боковая и вертикальная прибавки скорости по 2 м/с, затем оседание. Внутренние подшаги движка записываются отдельно. Сценарий фиксирован; он не пытается пройти круг или исправлять свою траекторию.

```sh
RRR3D_TRACE_FILE=/tmp/motorrock-solo.jsonl RRR3D_SEED=42 \
  /path/to/RRR3d.app/Contents/MacOS/RRR3d \
  --solo-physics-replay --track=0 --car=marauder
```

`solo.begin` записывает карту, автомобиль, число машин, отсутствие ИИ и начальный счётчик reset; `solo.drive` — фактические моменты двигателя/тормоза, передачу, RPM и угол руля перед подшагом; `solo.sample` — запрошенные команды, импульс, положение, ориентацию, скорость, угловой момент и параметры контакта/подвески/скольжения каждого колеса после шага. `solo.end` подтверждает завершение. UTC и монотонные временные метки остаются в общем формате лога; физические результаты сопоставляются по tick/substep, а не по времени выполнения процесса. Стартовое размещение backend увеличивает счётчик reset; проверяется отсутствие дальнейших изменений этого счётчика.

```sh
python3 tools/calibration/test_solo_replay.py \
  --exe=/path/to/RRR3d.app/Contents/MacOS/RRR3d \
  --output-dir=/tmp/motorrock-solo-check
```

Скрипт сохраняет выбранные пользователем физические флаги и профиль, запускает карты 0, 16, 48, 64 трижды (seed 42, 42, 999), проверяет полноту и конечность чисел, все этапы управления, отсутствие reset, фиксированную длительность шага и точное равенство численных команд/состояний. Он намеренно включает `RRR3D_AI_DRIVER=1`, проверяя изоляцию режима. Используйте новый каталог для каждого набора запусков: trace append не должен смешивать сессии.

В экспериментальном v21 source-mesh прототипе все 12 запусков совпали точно: 10 800 записей состояния. Это доказательство повторяемости Mac-прогона, а не совпадения с Windows. Новый игровой CLI пока доступен только на Mac; Windows по-прежнему проверяется отдельным стендом с исходным PhysX 2.8.4 без ИИ. Для сравнения одинаковой настоящей карты на двух платформах потребуется перенос этого протокола/геометрии в Windows reference runner. Меню, графика, полный Race lifecycle и поведение ИИ проверяются отдельно.
