# V99: fixture scene creation order and canonical contact roles

The Windows reference probe creates floor, cars, obstacle; the previous Mac backend created all track meshes and decorations before cars. Original Native border-front-grounded49 contacts put the static surface in body0 and the dynamic car in body1. Mac always supplied the car as cache body0 and selected its material reference frame from the SAT polygon. Equal world points, incoming body state and inertia therefore produced different local point rounding and a different normal/mass.

This four-file default-off investigation adds an explicit WorldDescription probe construction contract and preserves canonical contact roles in material/cache preparation. Existing body1 YZX local-point arithmetic now receives the dynamic body in the proper slot; cached lever selection follows that slot. Material normals use the proper canonical sign and are mapped back to the Jolt pair.
