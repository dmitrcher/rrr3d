# V189 — оригинальный метод прыжка, без ВМ

Оригинальный JumpProgress вызван на настоящем PhysX-объекте через CrossOver. На Mac использованы настоящий GameCar и Jolt. Все530 изолированных условий совпали в двух повторах: таймер, положение, скорость, поворот, угловой момент и состояние активности. При отключении V187 тест выявляет336 расхождений.

Дополнительно оригинальный метод прошёл две сохранённые Windows SDK-траектории по120 шагов в двух повторах. Mac совпал с этими же эталонами. Новый SDK-пробник предварительно прошёл три контрольные траектории по120 шагов.

Разница только в вычисляемом времени лога была устранена в новом пробнике. Поэлементная проверка до/после подтвердила отсутствие изменений физических результатов. Код физики Mac в этом этапе не менялся: проверялось уже принятое исправление V187.

Граница проверки:530 условий используют синтетический флаг контакта, а длинные эталонные траектории проходят в воздухе. Это не полная проверка реальных контактных переходов или игрового шага. CrossOver не заменяет Windows-эталон во всех условиях; несовпадающие ветки из V188 остаются исключёнными.

Подготовлен отдельный проверяемый диагностический пакет Mac. Обычная установленная игра и её профиль пока не переключены. ВМ не запускалась. Общая цель активна и не завершена.
