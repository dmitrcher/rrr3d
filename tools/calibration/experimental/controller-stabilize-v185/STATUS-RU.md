Проверенный результат V185: реальный GameCar Windows при PC24 и Source/Jolt совпадают в изолированном испытании стабилизации без сцепления. Проверены два тензора инерции: кузов отдельно и кузов с четырьмя колёсами. 720 разных входов помощника; O0/O2, по два повтора. В физическом мире: 180 вариантов без контактов, по два повтора. До исправления совпадало 69, после — 180. Случайного управления и других машин нет.

Условие закрытия полной цели: совпадение полного игрового обновления и обычных заездов, затем проверенная обычная сборка Mac с исправлениями. Одних численных помощников недостаточно. Экспериментальные флаги пока не включены в установленной пользовательской игре.

Следующие действия идут по порядку:
1. Сцепление: передать силу через GameCar → Session → физический мир и применять её внутри стабилизации; использовать фактическую массу актора. Удалить преждевременное потребление силы в контакте масла при включённом исправлении. Кандидат арифметики V186 проверяется по записанным вызовам Windows; это ещё не готовая интеграция.
2. Физические контакты: та же стабилизация при контакте передних/задних/всех колёс и кузова; включать только проверяемый эффект. Проверить смещённый центр массы и другие машины.
3. Прыжок и полный OnFixedStep: постоянная дополнительная гравитация Windows, угловое ускорение в воздухе, таймеры, последовательность операций. Затем воспроизводимый одиночный заезд с фиксированными командами и первое расхождение целого игрового шага.
4. После численного совпадения — обычная сборка Mac, обычный запуск и сравнение меню/графики/загрузочных событий. ИИ и столкновения с другими машинами проверять отдельно от одиночного эталона.

Общая регрессия запускается для законченного изменения. При локализации ошибки используются узкие испытания с точными входами; длинный заезд и все 608 сценариев не заменяют поиск первой неверной операции. Процессы, контрольные суммы сборок и реальные завершения проверяются явно; старые тестовые окна не считаются работающим тестом.

Для V185 введена явная отметка команды реального GameCar: его PC24 не применяется к искусственным SDK-командам PC53. Прежняя попытка без отметки давала 604/608; отчёт сохранён как отвергнутая версия. После исправления четыре затронутых сценария проходят по 120 кадров дважды. Реальная Session передаёт отметку на всех 900 шагах воспроизводимого контрольного запуска.

Окончательная регрессия V185 завершена: все 608 сценариев совпали в обоих повторах, по 255864 состояния. Также прошли 7200 состояний на трассах и 53 CTest. Полная цель остаётся открытой.
