# V188 — проверка пробников без виртуальной машины

ВМ Windows остаётся выключенной. Код физики Mac в этом этапе не менялся.

Оригинальный Windows SDK-пробник через отдельное окружение CrossOver повторил сохранённый Windows-эталон во всех608 сценариях:255864 состояния, два одинаковых физических повтора. Это позволяет запускать данный набор без Parallels.

Проверка более широких условий выявила ограничения. С оригинальной DirectX Math одна трасса совпадает на900 шагах в двух повторах. На трёх других начальный поворот уже отличается до первого шага. Стабилизация совпадает в885 из1440 случаев. Поэтому CrossOver нельзя автоматически считать новым Windows-эталоном для всех задач.

Первая отличающаяся операция стабилизации локализована: округление суммы при вычислении определителя. Все1380 записей этой ветки согласуются с сохранением промежуточной точности в Windows; все1380 записей CrossOver согласуются с округлением каждой суммы. Уже принятая формула Mac соответствует сохранённым данным Windows. Подстройка под другую среду ухудшила бы правильное поведение.

Промежуточное число1308/1440 было ошибкой нового вспомогательного сравнения: битовые слова нельзя преобразовывать во float перед сравнением. Сравнение исправлено, результат885/1440; эталоны и физика Mac не менялись.

Следующий конкретный этап — свежий изолированный пробник JumpProgress с одинаковым явно заданным начальным состоянием, проверка контактов и временных границ, затем полный игровой шаг. Оригинальный компилятор из имеющегося образа уже собрал свежую32-битную программу, которая успешно запустилась; пользовательские окружения не затронуты. Полные заезды, реальные столкновения/ИИ и визуальная проверка остаются открытыми. Общая цель не завершена.
