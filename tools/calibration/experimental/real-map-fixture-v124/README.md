# Real-map source fixture export V124

Optional `RRR3D_WORLD_FIXTURE_FILE_V124=PATH` during `--solo-physics-replay` exports the pre-creation WorldDescription as exactF32 words. It changes no physical parameters, game controls or simulation state. The current wire format is internal and will be extended as the Native replay reader is implemented.

Four original maps0,16,48,64 were run at seeds42/42/999 with one vehicle, no opponents and no AI/gameplay updates. Each900-step trajectory and every exported geometry/vehicle/decoration word repeats exactly per map. Shape counts and all index bounds are checked and the full wire is consumed. This proves Macrepeatability only. Windows real-map replay and trajectory comparison remain required, as do production integration and full game validation.

Wire: headerMOTORROCK_WORLD_V124; world7F32words; vehicle40words (boolindices15,16,19,37,38,39); wheelcount and23words/wheel (flags10,bool11/12); meshcount then14wordheaders (surface,decorationowner,position3,scale3,quaternion4,vertexcount,indexcount), vertex3F32words each and indices; decorationcount then27wordheaders (transform10,localposition3,localrotation4,halfextents3,skin,mass,sleepenergy,boolhasShape/dynamic/response,childcount),11F32words/child; spawncount then6F32words/spawn. Only singleton human spawns are covered. Owner IDs use the source unsigned size domain; all scalar words use uint32bitpatterns.

Optional `RRR3D_REAL_WORLD_ACTUATORS_V124=1` substitutes fixed raw wheel commands for the GameCar controller during this diagnostic only. The same900commands and delta velocities are executed in the experimental Native scene reader. Onecar/noAI runs repeat on eachbackend. Firstrealmap difference is28 (two suspension lengths, thenposition/angularmomentum/rotation); allbody/wheel states through27 match. Geometry assembly and originalWindows loader fidelity remain under verification. Flagoff preserves all900 previousgamecar samples and drivecommands.
