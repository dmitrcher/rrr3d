# V91 tire anchor lifetime

Native keeps a wheel's static friction reference point when its transient contact disappears. The old Mac adapter invalidated that anchor and reset it when contact returned. This default-off overlay preserves the existing anchor during absence; changed contact bodies and the existing displacement/skin update still follow their old paths. It changes no power, mass, grip, damping, suspension, threshold or step coefficients.
